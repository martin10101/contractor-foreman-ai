# Contractor Foreman AI (Product Context)

## Users
- Builders / contractors running multiple projects
- Office admin / accounting
- Project managers / foremen

## Primary goals
- Track projects, job sites, contacts, and tasks without losing details.
- Keep financials accountable: estimates, invoices, payments, and outstanding balance.
- Keep documentation organized: store important links/files per project/contact.
- Provide quick reporting: workload + cashflow overview.

## Success criteria
- A new user can run the app locally, log in, and create a project end-to-end.
- Every record is scoped to an organization (multi-tenant ready).
- Audit log captures key create/update/delete actions.
